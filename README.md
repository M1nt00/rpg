# 다섯 원소의 계승자

원소를 조합해 반응을 터뜨리는 **웹 브라우저용 턴제 파티 RPG**예요. 기획서(판타지 턴제 RPG 기획서)를 그대로 구현했어요.

- 장르: 턴제 파티 RPG (JRPG식) · 정통 판타지, 5원소
- 플랫폼: 웹 브라우저 (PC 우선, 모바일 터치 대응)
- 기술: HTML + CSS + TypeScript (Vite), 엔진·외부 에셋 없음 (그림은 SVG, 효과음은 Web Audio 합성)

## 바로 플레이

리포에 있는 **`play.html`** 을 브라우저로 열면 바로 실행돼요(더블클릭 OK, 설치 불필요).
`index.html`은 개발 서버용이라 직접 열면 실행되지 않아요.

## 개발

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist/ 에 정적 파일 생성 (어느 정적 호스팅에 올려도 동작)
npm run build:play # 빌드 후 한 파일짜리 play.html 다시 만들기 (코드 수정 후 실행)
npm test           # 전투 엔진·데이터 테스트
```

밸런스 시뮬레이션(휴리스틱 AI가 지역별 전투를 반복해 승률·남은 HP를 출력):

```bash
SIM=1 npx vitest run tests/balance.sim.test.ts
```

## 구현된 것

| 기획서 항목 | 구현 |
|---|---|
| 속도 타임라인 | 라운드 없음, 대기값 = 1000/SPD, 상단에 다음 8번 행동 미리보기, 행동 당기기·밀기, 속도 버프·디버프 |
| 행동 | 공격(MP+10) · 스킬 · 방어(피해 50%↓, MP+15) · 아이템 · 교대(턴 소모 없음, 전투당 2회) · 도망(보스전 불가) · 분석 |
| 원소 상성 | 물 → 불 → 바람 → 땅 → 번개 → 물, 유리 1.5배 / 불리 0.75배 |
| 원소 반응 8종 | 증발·감전·화염폭풍·진흙·과부하·모래폭풍·결정화·빙결 (2턴 부착, 다른 원소로 맞추면 발동) |
| 브레이크 | 약점 히트마다 게이지 감소 → 다음 행동 건너뜀 + 받는 피해 1.5배 → 게이지 회복, 보스 예고 기술 끊기 |
| 상태이상 | 화상·중독·기절·침묵·둔화 + 각종 버프/디버프, 보호막, 도발, 반격, 재생 |
| 데미지 공식 | ATK × 배율 × 100/(100+DEF) × 상성 × 반응 × 치명(1.5) × 난수(0.95~1.05), 마법은 MAG/RES |
| 파티 | 6명(계승자·카일·세린·아린·도윤·바르크), 출전 4 + 대기 2, 지역마다 합류 |
| 성장 | 레벨 상한 30, 레벨마다 SP 1, 캐릭터별 스킬트리 3갈래 + 궁극기, 전부 찍기 불가, 여관에서 초기화 |
| 장비 | 무기·방어구·장신구 2, 일반/희귀/영웅/전설(고유 효과), 무기 원소, 대장간 +1~+10 (+5까지 확정, 이후 실패해도 파괴 없음) |
| 적 | 지역마다 일반 4종 + 엘리트 + 보스, 규칙 기반 가중치 AI, 보스 2~3페이즈·예고 기술 |
| 보스 6체 | 잿불 골렘 · 호수의 마녀(분신) · 폭풍 그리폰(2회 행동) · 뇌신의 수호기(약점 변경) · 드워프 왕(암석 갑주) · 공허의 계승자(반응 모방, 3페이즈) |
| 맵 | 노드 이동식 월드맵 6지역 + 지역 맵 15노드(전투·엘리트·상자·이벤트·휴식처·마을·신전), 적이 보여서 피할 수 있음, 지도 완성 보상 |
| 퀘스트 | 메인 + 지역별 처치/수집/전달 + 동료 개인 퀘스트(전설 장비 보상) |
| 화면 | 타이틀 · 월드맵 · 지역 맵 · 마을(상점/대장간/여관/게시판) · 전투 · 파티 관리 · 인벤토리 |
| 저장 | localStorage 세이브 슬롯 3개(휴식처·여관에서 저장) + JSON 내보내기/불러오기 |
| 연출 | 반응 이름 크게 + 화면 흔들림, 브레이크 연출, 피해 숫자 색(일반 흰색 / 약점 노랑 / 반응 원소색 / 치명 큰 글씨), 스킬 대상에 올리면 반응 미리보기 |

## 폴더 구조

```
src/
  data/        skills.json, characters.json, enemies.json, items.json,
               regions.json, events.json, quests.json, scenes.json, index.ts
  battle/      core.ts(상태·타임라인·상태이상) damage.ts(공식·반응) ai.ts engine.ts(턴 흐름)
  game/        state.ts(능력치·성장) items.ts(장비·강화) world.ts(맵·보상·퀘스트·상점) save.ts
  ui/          battle.ts flow.ts(월드맵·지역 맵) town.ts party.ts inventory.ts menus.ts dialog.ts art.ts
  core/        dom.ts rng.ts audio.ts
tests/         battle.test.ts data.test.ts balance.sim.test.ts
tools/         gen-enemies.mjs gen-regions.mjs (JSON 재생성용, 선택)
```

- **데이터와 로직 분리**: 캐릭터·스킬·적·아이템·맵·대사는 전부 JSON. 밸런스는 숫자만 고치면 돼요.
  `enemies.json`/`regions.json`은 `tools/`의 생성 스크립트로 일괄 재생성할 수도 있어요
  (`node tools/gen-enemies.mjs src/data/enemies.json`).
- **전투 로직은 화면과 분리**: `src/battle/`은 DOM을 쓰지 않는 순수 로직이라 UI 없이 테스트돼요.
  난수는 시드 고정(mulberry32)이라 테스트가 재현 가능해요.
